# CookiecutterTemplates

A collection of opinionated [Cookiecutter](https://github.com/cookiecutter/cookiecutter) templates for Python projects.

## Templates

| Template | Description | Usage |
|----------|-------------|-------|
| **ModuleTemplate** | Modern Python module with uv, ruff, ty, pytest, poethepoet, and Claude Code integration | `cookiecutter gh:cabell132/CookiecutterTemplates --directory=ModuleTemplate` |
| **APISDKTemplate** | Python API/SDK project scaffold | `cookiecutter gh:cabell132/CookiecutterTemplates --directory=APISDKTemplate` |
| **data-science-project-template** | Data science project scaffold | `cookiecutter gh:cabell132/CookiecutterTemplates --directory=data-science-project-template` |

## Requirements

- [Cookiecutter](https://github.com/cookiecutter/cookiecutter) (`pip install cookiecutter` or `uv tool install cookiecutter`)
- [uv](https://github.com/astral-sh/uv) (recommended for generated projects)
